## 📌 Project Overview

This project builds a **binary fake news classifier** for **The TruthLens Institute** —
a global research organisation dedicated to combating misinformation and promoting
digital literacy.

Given the title and body text of a news article, the app predicts whether it is
**FAKE** or **REAL** using a complete 7-step NLP preprocessing pipeline and a
Tuned XGBoost Classifier.

| Attribute | Value |
|-----------|-------|
| **Best Model** | Tuned XGBoost Classifier |
| **Accuracy** | 86.75% |
| **ROC-AUC** | 0.9393 |
| **F1-Score (Fake)** | 0.87 |
| **F1-Score (Real)** | 0.87 |
| **Cross-Validation AUC** | 0.8987 (5-fold) |
| **Dataset** | 12,999 real-world news articles (8 misinformation categories) |
| **Final Training Set** | 826 balanced records (413 fake / 413 real) |
| **Feature Matrix** | 20,002 dimensions (TF-IDF + word_count + sentiment) |

## 🧠 Technical Pipeline

```
Raw Article (title + body text)
          │
          ▼
  ┌─────────────────────────────────────┐
  │         clean_text()                │
  │  Stage 1: Remove special chars      │
  │  Stage 2: Lowercase conversion      │
  │  Stage 3: Punctuation removal       │
  │  Stage 4: Tokenisation              │
  │  Stage 5: Stopword removal +        │
  │           WordNet Lemmatisation     │
  └─────────────────────────────────────┘
          │
          ├──────────────────────────────┐
          ▼                              ▼
   word_count               VADER compound sentiment
   (token count)            (score: −1.0 to +1.0)
          │                              │
          └──────────┬───────────────────┘
                     ▼
        TfidfVectorizer.transform()
        (20,000 features: unigrams + bigrams)
                     │
                     ▼
        scipy.sparse.hstack()
        → (1, 20,002) sparse matrix
                     │
                     ▼
        XGBClassifier.predict_proba()
        → FAKE / REAL + confidence score
```

## 🔧 Generating the Models

The `.joblib` files are produced by the training notebook. To regenerate them:

1. Open the training notebook in Google Colab
2. Run all cells through to the model saving step
3. The following files will be saved:
   - `tfidf_vectorizer.joblib` — fitted TF-IDF vectoriser
   - `tuned_xgboost_fake_news.joblib` — Tuned XGBoost (production)
   - `tuned_logistic_regression_fake_news.joblib` — Tuned LR (interpretability)
   - `label_encoder.joblib` — label encoder

Place all four files in the root directory alongside `app.py`.

## 📁 Dataset

The dataset is a real-world news crawl of **12,999 articles** published between
2015 and 2016, containing 20 columns including article content, publication metadata,
and engagement signals.

**Target column:** `type` — 8 misinformation categories

| Category | Count | Binary Label |
|----------|-------|-------------|
| `bs` | 11,492 | fake |
| `bias` | 443 | real (proxy) |
| `conspiracy` | 430 | fake |
| `hate` | 246 | fake |
| `satire` | 146 | fake |
| `state` | 121 | fake |
| `junksci` | 102 | fake |
| `fake` | 19 | fake |

After binary mapping, a **29.8:1 class imbalance** (fake:real) was addressed via
**random downsampling**, producing 826 balanced records (413 per class).

---

## 🔬 Key Technical Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Binary mapping | `bias` → real, all others → fake | `bias` is the only category representing grounded (if slanted) reporting |
| Class balancing | Downsampling to 413 per class | Downsampling preferred over SMOTE to avoid synthetic text patterns |
| Text representation | TF-IDF, max_features=20,000, ngram_range=(1,2) | Bigrams capture phrase-level patterns (e.g. "white house" vs "white"+"house") |
| Scaler | None | TF-IDF values are already in [0,1]; tree-based models are scale-invariant |
| Tuning objective | ROC-AUC | Threshold-independent; more robust than accuracy for content screening |
| Best model | XGBoost (tuned) | Highest accuracy, AUC, and balanced F1 across both classes |

## ⚠️ Limitations

- The model was trained on US political news from 2015–2016. Performance may vary on other domains, regions, or time periods.
- The "real" class is proxied by `bias` articles — ideologically slanted but factually grounded content. This is an imperfect ground truth.
- Training set is small (743 samples). The model may exhibit higher variance on unseen article styles.
- `site_url`, `published`, `domain_rank`, and `spam_score` metadata were excluded from the current pipeline — incorporating them could improve performance by 2–5 AUC points.
